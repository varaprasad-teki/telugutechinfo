# Creator Hub — YouTube Channel Website

A responsive, dark premium-style landing page for YouTube channel ID `UC72bhJUkOY94BxoiuTTlYIQ`.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript in one file).

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. An internet connection is needed for YouTube embeds and external links.

## Included
- Responsive desktop and mobile layout
- Dark design with red/orange accents
- Mobile navigation menu
- Channel subscribe buttons
- Channel uploads playlist embed
- Tech and education topic sections
- Accessibility labels and reduced-motion support

## Important YouTube note
The site embeds the uploads playlist ID derived from the channel ID (`UU72bhJUkOY94BxoiuTTlYIQ`). YouTube channel playlist embeds can occasionally fail if a channel's uploads playlist is unavailable or embedding is restricted. If that happens, the “View all” link still opens the channel's videos page.

## Customize
Open `index.html` in a code editor and change:
- `CREATOR HUB` to your preferred channel/brand name
- `TECH · EDUCATION · TELUGU` to your tagline
- Hero text and topic descriptions to match your exact content
- Accent colors in the `:root` CSS variables near the top

## Publish it free
You can publish this static site using GitHub Pages, Netlify, or Cloudflare Pages. Upload `index.html` (and this README if desired) to your chosen host, then follow its static-site publishing steps.
